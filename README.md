# 🏈 NFL Player Personnel Dashboard

An interactive fantasy football analytics dashboard built with Python and Streamlit.

## Features

- Weekly fantasy point analysis
- Home vs. Away splits
- Position-specific defensive matchup rankings
- Strength of Schedule analysis
- Interactive Plotly charts
- Position-wide player rankings
- CSV export

## Technologies

- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```

## Project Preview

The dashboard allows users to:
- Filter by position, team, and player
- View weekly fantasy production
- Analyze home and away performance
- Compare players against others at the same position
- Evaluate schedule difficulty using defensive rankings
